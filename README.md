# Python Event Manager

## Project Overview

The Python Event Manager is a command-line application developed to simplify event management through structured data handling and automated operations. The application allows users to manage event records, perform operations on stored data, and maintain event information using Python and CSV files.

The project demonstrates the application of Python programming concepts, modular programming, file handling, and software testing in developing a functional data management system.

## Key Features

- **Event Management:** Create, view, update and manage event records.
- **Data Handling:** Store and retrieve event information using CSV files.
- **Modular Programming:** Organised code structure separating event functionality from application logic.
- **Unit Testing:** Includes automated tests to verify application functionality and identify errors.
- **Data Persistence:** Maintain event records through CSV-based storage.

## Technologies Used

- Python
- CSV (Comma-Separated Values)
- Unittest (Python Testing Framework)

## Getting Started

### Prerequisites

- Python 3.x installed on your computer.

### Installation

1. Clone the repository:

```bash
git clone https://github.com/Gogathebrains4/python-event-manager.git
```

2. Navigate to the project directory:

```bash
cd python-event-manager
```

3. Run the application:

```bash
python event_manager.py
```

## Testing

The project includes unit tests to evaluate the functionality of the event management components.

Run the tests using:

```bash
python -m unittest discover -v
```
